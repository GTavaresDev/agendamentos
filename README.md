# Atempo

MVP de um sistema de agendamentos construído com Next.js, Tailwind CSS e componentes no padrão shadcn/ui.

## Rotas

- `/` — login
- `/dashboard` — visão geral
- `/agendamentos` — seleção de data e horário
- `/usuarios` — gestão de usuários
- `/relatorios` — indicadores e gráficos
- `/free-access` — landing page da clínica VisioNew
- `/free-access/links` — página pública de links

Todos os dados são simulados e não há dependência de APIs externas.

## Desenvolvimento

```bash
npm install
npm run dev
```

Para validar a aplicação:

```bash
npm run build
```
